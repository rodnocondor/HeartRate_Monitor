# PulseTrack — IoT-система мониторинга ЧСС

Автономное устройство для мониторинга частоты сердечных сокращений на базе ESP32, нагрудного BLE-кардиодатчика Polar H7 и локального TFT-дисплея с кнопочным (в перспективе — сенсорным) управлением.

Курсовой/дипломный проект по специальности IoT.

## Идея проекта

В отличие от готовых фитнес-приложений на смартфоне (которые тоже умеют принимать BLE Heart Rate Service напрямую), PulseTrack — это полностью **автономное устройство**: не требует телефона, интернета или внешней инфраструктуры. Вся обработка данных (расчёт пульсовых зон, вариабельности сердечного ритма, синхронной анимации) происходит локально на микроконтроллере.

## Функциональность

Целевая функциональность проекта (статус каждого пункта см. в разделах «Статус проекта» и «Roadmap»):

- Приём данных ЧСС и RR-интервалов от Polar H7 по BLE (профиль Heart Rate Service, 0x180D)
- Отображение текущего BPM крупным шрифтом на дисплее
- Анимированный значок сердца, пульсирующий синхронно с реальными RR-интервалами (не с частотой пакетов BLE)
- Определение и цветовая индикация пульсовых зон
- График/тренд BPM в реальном времени
- Меню: начало/завершение сессии, история сессий, настройки зон
- Автоматическое восстановление BLE-соединения при разрыве связи
- (опционально) Логирование сессий и расчёт HRV-метрик (RMSSD)

## Архитектура

```
Polar H7 --(BLE, Heart Rate Service)--> ESP32
                                          │
                                          ├── Парсинг пакетов (BPM, RR-интервалы)
                                          ├── Расчёт зон пульса и HRV
                                          ├── Планирование анимации по RR-интервалам
                                          └── Рендер на TFT-дисплей + обработка ввода
```

Система не использует WiFi/MQTT/облако — вся логика замкнута на связке ESP32 + датчик + дисплей, питание ESP32 — через USB.

## Аппаратная часть

| Компонент | Характеристики |
|---|---|
| Микроконтроллер | ESP32 (BLE + достаточное число GPIO под параллельный дисплей) |
| Кардиодатчик | Polar H7 (BLE, Heart Rate Service 0x180D) |
| Дисплей | 3.2" TFT, драйвер ILI9341, 240×320, 16-битная параллельная шина |
| Ввод (текущий) | 3 кнопки UP / DOWN / OK на GPIO 34, 35, 36 (внешняя подтяжка 10 кОм к 3V3, нажатие замыкает на GND) |
| Тач (планируется) | Резистивный, контроллер XPT2046 — в текущих скетчах не используется |
| Питание | USB от ПК |

### Подключение дисплея (ILI9341, 16-bit parallel)

Распиновка задана в блоке `LGFX` скетча `pulsetrack_display_test.ino`. При изменении проводки менять номера нужно только там.

| Сигнал дисплея | GPIO ESP32 |
|---|---|
| WR | 15 |
| RS (DC) | 4 |
| D0 – D7 | 2, 13, 14, 16, 17, 18, 19, 21 |
| D8 – D15 | 22, 23, 25, 26, 27, 32, 33, 5 |
| RD | не задействован (подтянут к 3V3) |
| CS | не задействован (посажен на GND) |
| RST | не задействован (заведён на EN) |

### Подключение кнопок

| Кнопка | GPIO |
|---|---|
| UP | 34 |
| DOWN | 35 |
| OK | 36 |

GPIO 34–39 на ESP32 работают только как входы и не имеют встроенной подтяжки, поэтому используются внешние резисторы 10 кОм к 3V3.

## Программный стек

- **Прошивка:** C++ (Arduino framework для ESP32)
- **BLE:** NimBLE-Arduino 2.x (автор h2zero), режим клиента/central
- **Графика/дисплей:** LovyanGFX (параллельный режим `Bus_Parallel16` для ILI9341)
- **Тач (планируется):** XPT2046_Touchscreen (или встроенный драйвер графической библиотеки)

Библиотеки устанавливаются через Arduino IDE → Sketch → Include Library → Manage Libraries.

## Статус проекта

🚧 В разработке — учебный проект по специальности IoT.

Выполнены первые два этапа roadmap. Каждый оформлен как отдельный самостоятельный скетч.

### `pulsetrack_ble_console.ino` — BLE-подключение и вывод BPM в Serial (этап 1)

Минимальный пример: ESP32 находит Polar H7, подключается к нему и выводит значение ЧСС в Serial Monitor.

Что реализовано:

- сканирование эфира и поиск устройства, которое рекламирует сервис Heart Rate Service (0x180D), без привязки к конкретному MAC-адресу;
- подключение как BLE-клиент и получение характеристики Heart Rate Measurement (0x2A37);
- подписка на нотификации характеристики;
- разбор пакета Heart Rate Measurement по спецификации Bluetooth SIG: учитывается бит формата в байте флагов, то есть BPM читается как UINT8 или UINT16;
- вывод строк вида `ЧСС: 72 BPM` в Serial Monitor;
- автоматическое восстановление связи: при разрыве соединения запускается повторное сканирование, пока датчик не будет найден снова.

Ограничения текущей версии:

- RR-интервалы пока не извлекаются из пакета — разбирается только BPM;
- пульсовые зоны, HRV и дисплей в этом скетче не используются.

Как запустить:

1. Установить библиотеку **NimBLE-Arduino** версии 2.x.
2. Выбрать плату ESP32 Dev Module (или свою конкретную плату).
3. Загрузить скетч, открыть Serial Monitor на скорости **115200 baud**.
4. Надеть датчик Polar H7 (смочить электроды) — в мониторе появятся сообщения о подключении и значения BPM.

### `pulsetrack_display_test.ino` — тест дисплея и кнопок (этап 2)

Скетч без BLE, проверяющий аппаратную часть: инициализацию дисплея, цвета и ввод с кнопок, а также содержащий статичный макет будущего главного экрана.

Что реализовано:

- конфигурация LovyanGFX для ILI9341 с 16-битной параллельной шиной (класс `LGFX`, все пины собраны в одном месте);
- проверка цветопередачи: последовательная заливка экрана красным, зелёным и синим;
- статичный макет главного экрана в портретной ориентации 240×320: строка статуса BLE, значок сердца (функция `drawHeart`), крупное значение BPM и подпись «BPM»;
- опрос трёх кнопок UP / DOWN / OK с определением момента нажатия по смене уровня и выводом `Кнопка UP/DOWN/OK` в Serial Monitor.

Ограничения текущей версии:

- значение BPM на экране — заглушка (`128`), реальные данные с датчика пока не подключены;
- индикация пульсовой зоны и анимация сердца ещё не реализованы;
- сенсорный слой не используется, навигация пока задумана на кнопках;
- опрос кнопок идёт без программной защиты от дребезга (в основном цикле стоит задержка 20 мс).

Подсказки по настройке (параметры в блоке `LGFX`):

- при артефактах на экране снизить `freq_write` с 20 МГц до 10 МГц;
- если цвета инвертированы — поставить `invert = true`;
- если красный и синий поменялись местами — поставить `rgb_order = true`.

Как запустить:

1. Установить библиотеку **LovyanGFX**.
2. Собрать схему согласно таблицам подключения выше.
3. Загрузить скетч, открыть Serial Monitor на скорости **115200 baud**.
4. Убедиться, что экран по очереди заливается красным, зелёным, синим, затем показывает макет; нажатия кнопок отображаются в мониторе.

## Принцип работы (целевой)

1. ESP32 сканирует эфир и подключается к Polar H7 как BLE-центральное устройство *(реализовано в `pulsetrack_ble_console.ino`)*
2. Подписывается на нотификации характеристики Heart Rate Measurement (0x2A37) *(реализовано)*
3. При получении пакета извлекает BPM и массив RR-интервалов *(BPM реализовано, RR — в планах)*
4. Вместо мгновенной реакции на пакет — планирует серию событий "удар" во времени по значениям RR (первый сразу, следующий через RR[0] мс и т.д.), используя неблокирующие таймеры на `millis()`
5. По каждому запланированному "удару" запускается анимация сердца на экране (масштаб/цвет), синхронная с реальным ритмом
6. Параллельно рассчитываются пульсовая зона и (опционально) HRV, обновляется график тренда
7. Слой ввода (кнопки, в перспективе тач) опрашивается в том же цикле, не блокируя BLE-обработку; нажатия переключают состояния экрана (конечный автомат: главный экран / меню / история / настройки)
